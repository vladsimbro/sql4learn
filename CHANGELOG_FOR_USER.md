# Изменения SQL4LEARN для владельца

## 12 ноября 2026 — версия 0.11: надёжность практики и честный аудит

Проведено исследование исходников, опубликованного сайта и 15 образовательных ресурсов. Рабочую основу сохраняем: полный перезапуск сейчас не оправдан. Подробные выводы и план находятся в docs/PROJECT_STATUS.md.

Что изменилось:

- Долгий SQL больше не выполняется в потоке интерфейса: зависший запрос останавливается, учебные данные восстанавливаются. Добавлены понятные ограничения объёма ответа.
- SQL-движок загружается вместе с сайтом, без зависимости от стороннего CDN.
- Сайт должен пройти браузерную проверку перед публикацией; опубликованная версия связывается с конкретным коммитом.
- В первых уроках объяснены арифметические знаки, кавычки, устройство таблиц и сокращённые имена таблиц.
- Повторение продолжает менять задачи после четвёртого успешного цикла.
- В проекте поддержки неверные события до открытия обращения не считаются ответами. Складской проект сравнивает остатки на один момент времени; допущения расчёта явно объяснены.
- Улучшены контраст, работа клавиатурой, импорт, объявления результатов и сохранение фокуса редактора.
- Если браузер не сохраняет прогресс, видно предупреждение и можно скачать копию, включая результаты из памяти вкладки.

Что ещё не закончено: профессиональный курс PostgreSQL, лаборатории транзакций и оптимизации, независимая оценка уровня, поиск и справочник. Реальные ученики ещё не участвовали в проверке методики. Нынешний курс не выдаётся за законченную академию или полную подготовку аналитика.

Следующий приоритет — точные правила проверки типов/чисел и самостоятельная проверка базовых компетенций; затем PostgreSQL лаборатории. Результаты релизных проверок, коммит и публикация сообщаются отдельно после подтверждения.

# SQL4Learn — понятный журнал изменений

## Разрабатываем 0.10 · Полная переработка «Учебного маршрута» (кандидат)

Сосредоточились на единственной вкладке: **курсе SQL для аналитики**. Сохранили девять модулей, все старые решения и прогресс, но добавили 19 действительно новых уроков с объяснениями простыми словами: строки, типы, преобразования, числа, проценты, первичные и внешние ключи, CROSS/SELF JOIN, UNION/INTERSECT/EXCEPT, безопасные отрицательные подзапросы, коррелированные SELECT, STRING_AGG, LEAD, оконные рамки, FIRST/LAST_VALUE, NTILE, медиану и ROLLUP. Общее число уроков — **63**, основных задач — **190**.

В каждом уроке теперь есть собственный пошаговый путь рассуждения (три этапа), а в шестнадцати сложных темах — маленькие таблицы с наглядным изменением строк. Внутри учебной задачи доступны три раскрываемые подсказки, которые не выдают эталонный SQL сразу. Добавили 14 новых самостоятельных задач в прежние уроки с недостаточной практикой. При неправильном SQL внутри урока теперь показывается, какие именно столбцы отсутствуют, сколько строк ожидалось или какая примерная строка расходится. Наглядные таблицы помечены как условные, чтобы их не путали с реальной учебной базой.

**Пока не выпущено:** готовится проверка всех примеров и задач на двух базах PostgreSQL, затем публикация и браузерная приёмка. Не переключаем разработку на другие вкладки. Отдельно нужно пройти учебник с реальными новичками, чтобы оценить педагогическое качество, которое автоматические тесты измерить не могут.

## Релиз 0.9 · Складской аудит (опубликован)

Добавляем второй полноценный самостоятельный проект **Inventory Control**. Вместо очередных задач на доставку появилась новая схема учёта товаров: склады, ассортимент, стартовые остатки, приход и расход, повторные инвентаризации. Нужно самостоятельно сделать шесть взаимосвязанных отчётов: восстановить остатки, найти дефицит, сверить учёт с физическим пересчётом, рассчитать оборот, найти позиции без движения и сформировать итог аудита.

В данных специально есть отрицательный остаток, повторные пересчёты, движение ровно на границе отчётного времени и товары без начального остатка. Второй набор данных добавляет два склада (один без единого пересчёта), SKU и аномалии. Проверка должна отличать работающий запрос от запроса, который случайно совпал с одним примером. Есть отдельное поле аналитической записки и схема для самостоятельного исследования.

**Опубликовано и проверено:** PR [#9](https://github.com/vladsimbro/sql4learn/pull/9) слит в `main` (`132317531a5437f18505d663aa3b674bf0e57bce`), [GitHub Actions #43114868694](https://github.com/vladsimbro/sql4learn/actions/runs/43114868694): SQL-тесты, публикация и браузерные проверки **SUCCESS**. Прежний Support Ops и весь учебный прогресс сохранены. Письменные выводы по-прежнему не оцениваются автоматически.

## Релиз 0.8 · Делаем обучение последовательным (опубликован)

Пока работали над учебником, в основной версии уже вышло повторение SQL 0.7. **Мы его сохранили** и объединили с новой методикой, а не выбросили ради изменения интерфейса.

В учебном курсе теперь **44 урока, 119 обычных SQL-задач**. Для каждого урока написано, что ученик должен понять, какие старые темы пригодятся, какой результат нужно предсказать и где обычно возникает логическая ошибка. Можно заранее предположить число строк и сразу сверить с PostgreSQL.

Исправили конкретные пробелы: LIMIT, CASE и логический порядок SQL получили собственные уроки; дата-практика больше не опережает тему времени, а ранний поиск отсутствующих связей не требует ещё не изученного NOT EXISTS. Контроль качества данных идёт до продуктовой аналитики. В SQL X-Ray появилась шестишаговая демонстрация FROM → WHERE → GROUP BY → HAVING → ORDER BY → LIMIT.

**Дополнительная ревизия 11 ноября:** убрали устаревшее утверждение, будто интервальное повторение 0.7 ещё не готово; исправили ссылку на ветку PR №8. Добавили автоматическое правило: в каждом уроке должно быть от двух до пяти разных по условию SQL-задач. Проверка исходного курса вручную подтверждает 44 урока и 119 заданий, но не заменяет их реального запуска на PostgreSQL.

**Опубликовано и подтверждено:** PR №8 объединён в `main`, коммит `024040b7cad6ea145075d3a50e76014c717e027f`. GitHub Actions [#43112925459](https://github.com/vladsimbro/sql4learn/actions/runs/43112925459): проверка SQL, публикация на Pages и браузерное тестирование — **SUCCESS**. Это подтверждение технической работоспособности, а не независимая оценка качества обучения новичками.
