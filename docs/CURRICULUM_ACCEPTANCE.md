# SQL4Learn — приёмка учебного маршрута 0.10

## Область работ

Только вкладка **«Учебный маршрут»**, общие SQL-данные и проверки, необходимые для уроков. Другие страницы платформы не перепроектируются. Все существующие ID уроков, заданий, модулей, контрольных и формат локального прогресса сохраняются.

## Учебный состав

- 9 упорядоченных модулей, 63 урока, 190 основных SQL-задач.
- 19 новых уроков с теорией, рабочим примером, вопросом на понимание, уникальным прогнозом, типичной ошибкой и тремя упражнениями.
- 14 новых задач к ранее коротким урокам.
- 63 авторских пошаговых разбора по три логических этапа и 16 наглядных превращений «исходные строки → результат».
- Три раскрываемых уровня подсказок для заданий внутри урока, без немедленного показа эталона.
- Все 6 ранее опубликованных контрольных и 14 экзаменационных заданий сохранены.

## Автоматические критерии

1. Для каждого урока есть 2–5 самостоятельных SQL-заданий с уникальными ID.
2. Все зависимости от предыдущих уроков корректны; тема не требует будущих конструкций в обязательной практике.
3. Для каждой темы есть конкретная цель, прогноз, типичная ошибка и три самостоятельных шага объяснения.
4. Все SQL-примеры и все эталонные решения выполняются в PGlite/PostgreSQL на основной и изменённой базах.
5. Проверка принимает эквивалентные SELECT и WITH…SELECT, учитывает имена столбцов, значения, повторы, при необходимости сортировку.
6. В Pull Request отдельно проверяются локальным Chromium переходы между модулями, интерактивный пример, прогноз, мини-таблицы, раскрываемые подсказки, диагностика неверного SQL, SQL-редактор, повторное открытие после перезагрузки и мобильная навигация; на main после публикации запускается повторный браузерный smoke-test.
7. Публикация подтверждается validate, GitHub Pages deploy и браузерным тестом на опубликованном сайте.

## Редакционные критерии, которые нельзя закрыть только CI

- Новичок после объяснения способен своими словами описать, что означает строка результата.
- Есть независимая новая задача, которую можно решить без повтора эталонного SQL.
- Примеры показывают не только «счастливый путь», но и границы, NULL, потери строк и размножение при JOIN.
- Нет неверных утверждений о порядке физического выполнения: логический порядок SQL — модель смысла, оптимизатор выбирает свой физический план.
- Учебник проверен пробными полными прохождениями нескольких людей без начальных знаний SQL, с документированием трудных мест.

## Границы программы

Это полный расширенный **SELECT-маршрут для аналитики**, а не курс администрирования PostgreSQL и не сертифицированная профессиональная академия. Работа с CREATE/INSERT/UPDATE/DELETE, транзакциями, индексами и планами выполнения потребует отдельной безопасной практической инфраструктуры, а не фиктивных действий в SELECT-only редакторе. **Не переходить к другим вкладкам, пока учебный маршрут не прошёл содержательную приёмку.**
