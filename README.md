# SQL4LEARN

Русскоязычная учебная платформа SQL: реальный PostgreSQL в браузере, самостоятельные запросы и проверка результатов на двух наборах данных.

[Открыть сайт](https://vladsimbro.github.io/sql4learn/) · [Статус разработки](docs/PROJECT_STATUS.md) · [Изменения для владельца](CHANGELOG_FOR_USER.md)

## Версия 0.11.0

Изолированный SQL-движок с принудительным тайм-аутом и восстановлением; локальный PGlite, чистая сборка, проверки до публикации. Исправлены начальные объяснения, ротация повторения, временная логика SLA и складских остатков. Улучшены клавиатурная навигация, контраст и сообщения об ошибках сохранения.

В приложении 9 модулей, 63 урока и 190 основных SQL-задач, 6 контрольных (14 задач), 13 диагностических заданий, 2 независимых проекта (12 задач), 27 вариантов повторения и 8 SQL X-Ray сценариев. Количество не означает завершённую профессиональную академию.

Реализованный маршрут — преимущественно читающий SQL для аналитики. DDL/DML, многосессионные транзакции, индексы/оптимизация, JSONB и администрирование пока не представлены полноценными курсами. SQL не заменяет статистику, BI и остальные профессиональные знания аналитика. Прогресс хранится в этом браузере, с ручным экспортом/импортом, без аккаунтов.

## Локальный запуск

Node.js 22+ и Python 3. После установки зависимостей SQL-движок работает из локальных файлов, CDN не нужен.

```bash
npm ci
npm run dev
```

Открыть http://127.0.0.1:4173/. `npm run build` создаёт dist; `npm run serve` раздаёт уже собранный dist.

## Проверки

```bash
npm test
npm run build
npx playwright install chromium
npm run serve
# В другом терминале:
npm run test:browser
```

Браузерный набор включает настоящий SQL, неверные/альтернативные решения, проекты, сохранение, timeout/recovery, ошибки хранилища и axe обеих тем. Для системного Chromium: `CHROMIUM_PATH=/usr/bin/chromium`; для другого сайта: `BASE_URL=https://.../`. Unit/SQL-файлы исполняются последовательно для ограничения памяти WASM.

## Архитектура и качество

Vanilla JS ES modules и GitHub Pages. PGlite 0.5.15 в Web Worker, две базы, read-only транзакции, cursor cap 1000 строк. Worker не является строгой квотой памяти ОС. Решения и проверочные данные доступны клиенту — это учебная проверка, не защищённая аттестация.

CI проверяет SQL и собранный сайт до публикации, публикует только проверенный dist, затем проверяет `release.json` и живую версию. Статус конкретного SHA: [GitHub Actions](https://github.com/vladsimbro/sql4learn/actions), [манифест сайта](https://vladsimbro.github.io/sql4learn/release.json).
