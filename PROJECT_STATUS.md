**Дата:** 11 ноября 2026

**Репозиторий:** https://github.com/vladsimbro/sql4learn

## Текущий завершённый кодовый объём

- Новый с нуля дизайн, маршрутизация, светлая/тёмная темы, мобильное меню.
- 6 доступных модулей, 24 оригинальных урока и 58 проверяемых задач в `src/content.js`.
- 3 накопительные контрольные по 2 задачам в `src/assessments.js`.
- Нормализованная схема 5 таблиц доставки и два варианта данных в `src/data.js`.
- PostgreSQL через PGlite, транзакции READ ONLY, сравнение результатов и второго набора данных в `src/sql.js`.
- Отдельные статусы чтения, понимания и SQL, сохранение черновиков и резервные копии.
- Тесты SQL и пользовательского интерфейса + сборка GitHub Pages через Actions.

**Критически важно:** наличие файлов в ветке ещё не означает подтверждённого релиза. ## Следующий шаг

1. Добавить **SQL X-Ray**: интерактивную пошаговую визуализацию реальных строк PostgreSQL при JOIN, фильтрации, группировке и оконных вычислениях.
2. Добавить «Клинику ошибок»: студент исправляет неверный, но синтаксически допустимый SQL.
3. Продолжать основной курс: даты, временная аналитика, сложные JOIN, когорты и качество данных.
4. При каждом релизе подтверждать SQL-тесты, браузерный сценарий и GitHub Pages, обновляя SHA.

## Ограничения MVP

Проверки выполняются на двух данных наборах в браузере: это не скрытые серверные экзамены. Локальный прогресс без аккаунтов. Комплексные независимые проекты и профессиональный выпускной экзамен ещё не готовы. Эти ограничения нельзя скрывать за общим количеством уроков.
