# SQL4Learn

**Релиз 0.5 опубликован и проверен:** [открыть SQL4Learn](https://vladsimbro.github.io/sql4learn/). Проверка GitHub Actions: [#43084009950](https://github.com/vladsimbro/sql4learn/actions/runs/43084009950) — SQL, публикация и браузерный сценарий успешно пройдены.

**Учись думать данными, а не заучивать SQL.** Новый самостоятельный учебный проект: интерактивные уроки на русском, настоящий PostgreSQL в браузере, оригинальные бизнес-кейсы и проверка по результату запроса.

## Новый самостоятельный проект (в разработке, ветка `feature/independent-support-project`)

**Support Ops** — исследование полностью новой для курса предметной области через четыре таблицы отдельной схемы `support`. Шесть связанных отчётов, просмотр таблиц, SLA 60 минут, аномалии истории и аналитическая записка. SQL оценивается на двух наборах данных, текстовые выводы сохраняются без автоматической оценки. Это рабочая ветка; не считать её опубликованной до CI и browser-smoke.

## Что уже реально реализовано

- **9 модулей, 41 урок, 109 оригинальных SQL-задач.** Начинаем с исполняемого `SELECT` сразу в первом уроке; после каждого занятия есть несколько задач.
- 6 накопительных SQL-контрольных: ещё **14 независимых заданий**, объединяющих пройденные темы.
- **SQL X-Ray:** 7 живых экспериментов, 27 шагов PostgreSQL — зерно, JOIN fan-out, LEFT JOIN, GROUP BY, оконные вычисления, календарные дни без заказов, события и конверсию пользователей.
- **Клиника ошибок:** 13 оригинальных задач на исправление неправильного, но синтаксически допустимого SQL, с автоматической проверкой на двух наборах данных.
- Новая таблица **order_events** с историей состояния заказов, аномалиями и альтернативным набором для проверки двойного fan-out.
- **Все авторские примеры в уроках выполняются в PostgreSQL**: студент сначала предсказывает результат, затем видит таблицу ответа.
- Отдельный событийный домен: **app_users + user_events** с регистрациями, каналами, просмотрами, покупками и изменённой историей для проверки конверсии и когорт.
- PGlite (PostgreSQL в браузере). SQL-песочница и редактор внутри уроков. Разрешены только читающие `SELECT` и `WITH … SELECT`; операции записи блокируются транзакцией `READ ONLY`.
- Результаты сравниваются по именам столбцов, значениям, числу строк и повторениям. Порядок учитывается, только когда он требуетcя. Проверка выполняется на **основном и изменённом наборе данных**.
- Отдельные статусы чтения, вопроса на понимание и самостоятельной SQL-практики.
- Прогресс и черновики сохраняются локально, доступен экспорт/импорт JSON, светлая и тёмная темы, мобильная версия.
- Два тематических кейса **Delivery Pulse** (доставка) и **Growth Signals** (продуктовая аналитика) на задачах курса. Это пока не независимые финальные проекты.

Не выдаём 41 реализованный урок за полностью готовую академию. Следующие темы и самостоятельные проекты открываются в последующих релизах, как описано в [ROADMAP.md](ROADMAP.md).

## Запуск локально

Нужен Node.js 22+ и интернет для первой загрузки PGlite из CDN.

```bash
npm install
npm run serve
```

Открой [http://localhost:4173/](http://localhost:4173/).

Проверки:

```bash
npm test
npx playwright install chromium
npm run test:browser
```

`npm test` выполняет эталонные запросы **в PostgreSQL** на двух вариантах данных, проверяет структуру учебника, безопасное чтение и миграцию прогресса. Браузерный сценарий проверяет UI, сохранение черновиков и мобильную навигацию.

## Публикация

Основной репозиторий: https://github.com/vladsimbro/sql4learn

После проверки workflow публикует статический сайт на [GitHub Pages](https://vladsimbro.github.io/sql4learn/). Отдельный сервер и база в облаке не требуются: PGlite и учебные данные запускаются в браузере.

**Ограничения:** дополнительный набор данных технически доступен клиенту; это проверка устойчивости SQL, а не секретный античит. Для защищённых экзаменов и личных кабинетов в будущем понадобится серверная инфраструктура. Локальный прогресс не синхронизируется между устройствами без импорта резервной копии.
