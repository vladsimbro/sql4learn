# Текущее состояние SQL4LEARN

Обновлено 12.11.2026. Это единый источник статуса; предыдущие корневые журналы сохранены в Git.

## Фаза

Глубокая модернизация существующей платформы, версия 0.11.0. Полная профессиональная академия ещё не завершена. Решение сохраняет работающие уроки и данные прогресса; новая конкурирующая реализация не создаётся.

## Сделано

- Проверен исходный main `95b4f3f4195588d8b45774140cf22e0b527508f5`, опубликованный app.js совпал с ним, исходные SQL/browser проверки прошли.
- Созданы технический, контентный, UX аудиты, исследование 15 ресурсов и карта пяти направлений с пятью уровнями. Оценки конкурентов ограничены действительно просмотренными/выполненными сценариями.
- Изолированный SQL runtime: Worker, hard deadline, terminate/reseed, cursor limit, ограничения размера SQL/ответа, read-only и две проверочные базы. Все существующие примеры/эталоны проходят через cursor protocol.
- PGlite размещается в сборке; чистый dist, npm ci, browser до публикации, release.json с SHA и последующая проверка live.
- Исправлены ранние объяснения и зависимости; непрерывная ротация review с миграцией; первый ответ/SLA с невалидными ранними событиями; Inventory с приведением остатков к одной временной точке и контрпримером.
- Клавиатура/фокус, импорт/экспорт, live feedback, контраст обеих тем; видимое предупреждение при ошибке localStorage с экспортом результатов из памяти.
- Добавлены регрессии содержимого, ссылок/DOM ID, SQL edge cases, сохранения, deadline/recovery и автоматической доступности.

## Проверки

Основной браузерный сценарий на новой сборке пройден; runtime browser отдельно подтвердил timeout/recovery, SQL cap, загрузку без CDN, ошибки и повторный запуск движка, stale-result защиту, skip-link и мобильную клавиатуру. Axe: восемь desktop сочетаний четырёх страниц/двух тем без нарушений. Это ограниченный автоматический и сценарный аудит, не пользовательское исследование или сертификат WCAG.

Финальный локальный прогон после последних исправлений прошёл: `npm test` — 5 файлов, 0 ошибок (содержимое, образовательные регрессии, ссылки/DOM, runtime, storage); сборка и синтаксис всех JS-модулей без ошибок; `npm run test:browser` — обе серии успешно завершились на dist в Chromium. Вторая серия также проверила отказ localStorage и содержимое экспортированной копии. Ссылка релизного коммита и результат удалённой публикации фиксируются в отчёте владельцу и GitHub Actions. Публикуется только прошедший browser artifact.

## Что остаётся

- Полноценные уроки и практика PostgreSQL DDL/DML/транзакций/индексов/JSONB/планов, рекурсия и серверные многосессионные лаборатории.
- Полный контракт типов/OID/числовых допусков SQL judge и дополнительные adversarial наборы.
- Долговременная история попыток/подсказок, независимые уровневые экзамены и экспертная оценка выводов.
- Поиск и отдельный справочник, дальнейшая мобильная эргономика схем/редактора.
- Проверка реальными новичками, low-end устройствами и ассистивными технологиями.
- Прогресс локальный, без аккаунтов/синхронизации. Worker не даёт строгой квоты памяти браузерного процесса. Эталоны и alternate данные доступны в браузере.

## Публикация и следующий шаг

Работа ведётся в `vladsimbro/sql4learn`, основная ветка main. Исходная версия восстановима по upstream SHA выше. Статус публикации текущего коммита проверяется в [Actions](https://github.com/vladsimbro/sql4learn/actions) и [release.json](https://vladsimbro.github.io/sql4learn/release.json); отсутствие успешного run нельзя интерпретировать как релиз.

Следующий обязательный продуктовый блок: формализовать typed grading contracts и независимый Foundation checkpoint, затем разработать PostgreSQL лаборатории с реальной изоляцией. Детали/зависимости/критерии — ROADMAP.md и CURRICULUM.md. Количественный процент готовности не приводится: нет проверенной весовой модели полного академического продукта.

В настройках репозитория отдельно обнаружен `build_type: legacy`, source main `/`. Он запускает системный `pages-build-deployment` (workflow414980466) параллельно нашему workflow и может публиковать исходники без vendor. В релизе лишний run43126356831 остановлен, затем успешно опубликован проверенный dist. Это не постоянное исправление настройки.

Попытка PUT Pages `build_type=workflow` получила GitHub403 (Resource not accessible by integration); попытка отключить системный workflow —422 (Unable to disable this workflow). Владелец уведомлён: [Settings → Pages](https://github.com/vladsimbro/sql4learn/settings/pages), Build and deployment → Source → **GitHub Actions**. До подтверждения этого переключения риск следующего конкурирующего legacy-деплоя остаётся открытым. Это ограничение прав GitHub, а не отказ автоматического approval-review. Проверенный текущий выпуск доступен.
